## Information Required for Troubleshooting

When raising API issues with [**Developer**](https://betfairdevelopersupport.zendesk.com/hc/en-us/requests/new)[**Support**](https://support.developer.betfair.com/hc/en-us/requests/new)  please provide the following details as this will help us to fully investigate any issues in a timely manner:

**Your details:**

* Applicaton Key used to make the request/s
* The ErrorCode/UUID (if exception) e.g. **“errorCode :  UNEXPECTED\_ERROR**

**API Request details:**

* Date/Time of the issue with timezone
* Operation/Endpoint URL
* connectionId (*Exchange Stream API only)*
* JSON request
* JSON response

**Issue Details**

* Expected behavior
* Actual behavior
