Quick Start Exchange API Products The Exchange API contains a powerful set of features that enable advanced market navigation, search, odds retrieval, bet placement and sports related data retrieval and includes the following key components: Betting APIExchange markets navigation, odds retrieval and bet placement operations. Reporting functionality relating to settled bets is also available. Accounts APIAccount related operations such as the ability to retrieve your available account balance & market P&L. Exchange Stream APIProvides low latency access market data allowing you to subscribe to and efficiently track changes to market, price, and orders. Other API's Other API'sAccount related operations such as the ability to retrieve your available account balance & market P&L. Exchange Stream APIProvides low latency access market data allowing you to subscribe to and efficiently track changes to market, price, and orders. Heartbeat APIAutomatically cancel unmatched bets in the event of your API client/s losing connectivity. Race Status APIEstablish the status of a horse race or greyhound market both prior to and after the start of the race. Historical Data APIEnables automated downloads of data purchased from the Betfair Historical data service.
